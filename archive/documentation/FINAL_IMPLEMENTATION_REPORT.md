## 📊 بنية قاعدة البيانات

### الجداول الرئيسية الموجودة:

1. **service_tickets** - طلبات الصيانة
2. **quotes** - عروض الأسعار
3. **quote_items** - عناصر عروض الأسعار
4. **orders** - الطلبات
5. **order_items** - عناصر الطلبات
6. **products** - المنتجات
7. **machines** - الآلات
8. **profiles** - ملفات المستخدمين

### الجداول المضافة:

1. **inventory_reservations** - حجوزات المخزون
2. **inventory_logs** - سجل تغييرات المخزون
3. **stock_alerts** - تنبيهات المخزون
