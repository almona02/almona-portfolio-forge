# Fix PowerShell Extension Terminal

## Quick Fix

### Option 1: Restart Extension (Recommended)

1. **Click "Restart"** in the popup dialog
   - Or press `Ctrl+Shift+P`
   - Type: `PowerShell: Restart PowerShell Extension`
   - Press Enter

2. **Wait 10-20 seconds** for extension to reload

3. **Open new terminal**:
   - Press `` Ctrl+` `` (backtick)
   - Or: Terminal → New Terminal
   - Select "PowerShell" from dropdown

### Option 2: Reload VS Code Window

1. Press `Ctrl+Shift+P`
2. Type: `Developer: Reload Window`
3. Press Enter
4. Wait for VS Code to reload

### Option 3: Reinstall Extension

If restart doesn't work:

1. Press `Ctrl+Shift+X` (Extensions)
2. Search: "PowerShell"
3. Click gear icon → **Uninstall**
4. Click **Install** again
5. Reload VS Code
