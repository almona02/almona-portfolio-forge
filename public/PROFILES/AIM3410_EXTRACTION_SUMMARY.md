#### Page 11: AIMCAM Programming
- **ISO programming language (G and M codes)** is used for easy programming in the creation of macro programs
- Thanks to the ISO programming language, it is very easy to write all kinds of machine operations
- Management of all machine functions can be easily provided
- When the measurement values required by the macro-operation are entered by the operator, the machine automatically creates the program in the background
- Can perform the selected macro operation on the profile
- While programming the required macro, it is possible to change the speed, cutting speed, tool number, profile reference point
- The program can be run quickly by entering the profile height and width measurement from the screen, without the need to get a tool zero each time according to the profile

## Key Findings

### G-code Programming:
1. **ISO G-code Language**: Standard ISO 'G' code programming language supported
2. **Macro Programs**: ISO programming language (G and M codes) used for macro program creation
3. **Automatic Generation**: Machine automatically creates program in background when macro-operation values are entered
4. **AIMCAM Software**: Customer-specific graphic drawings and automatic G-code creation

### Machine Capabilities:
1. **4-Axis CNC**: X, Y, Z, A axes with full range of motion
2. **Tool Magazine**: 8 tools (7 cutters + 1 saw blade) with mobile bridge design
3. **Operations**: Multi-piece operations (holes, slots, notching, saw blade cuts)
4. **Machinable Faces**: 
   - With milling tool: 1+2+2 (top + side faces + end)
   - With saw tool: 1+2+2 (top + side faces + ends)

### Control System:
1. **Tool Table**: Storing tool parameters and offsets
2. **CNC Setting Tables**: Machine parameters for maintenance
3. **Automatic Features**: Clamp positioning, tool cooling, profile support
