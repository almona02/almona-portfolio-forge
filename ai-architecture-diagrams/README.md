# AI Architecture Diagrams - Stakeholder Views

**One Platform, Six Perspectives**

This directory contains professional HTML/SVG diagrams that present the Almona Portfolio Forge AI architecture from different stakeholder perspectives. Each diagram emphasizes different aspects of the same powerful system, optimized for specific audiences, concerns, and trust requirements.

## 📁 Files

- **`index.html`** - Master navigation page with links to all stakeholder views
- **`investors.html`** - Defensible AI + Scalable Moat (for investors)
- **`enterprises.html`** - Control, Safety & Auditability (for enterprises)
- **`workshops.html`** - Speed, Fewer Mistakes, More Money (for workshops)
- **`machine-suppliers.html`** - Fewer Errors, Happier Customers (for machine suppliers)
- **`profile-suppliers.html`** - Digital Assets (for profile suppliers/extruders)
- **`governments.html`** - Transparency & Accountability (for governments/public buyers)

## 🎯 Usage

### For Presentations

1. Open `index.html` in a browser
2. Navigate to the relevant stakeholder view
3. Use full-screen mode (F11) for presentations
4. Diagrams are SVG-based and scale perfectly

### For Documentation

- Embed links in pitch decks, proposals, or documentation
- Print-friendly: All pages use clean layouts suitable for printing
- Mobile-responsive: Diagrams adapt to different screen sizes

### For Customization

All diagrams are built with:
- **HTML5** for structure
- **SVG** for scalable vector graphics
- **CSS** for styling (inline for portability)

To customize:
1. Edit the HTML files directly
2. Modify SVG viewBox and coordinates as needed
3. Adjust colors in CSS gradients

## 🎨 Design Principles

### Core Principle

**Same Platform, Different Lenses**

We do NOT change the platform. We only change WHAT is emphasized and WHAT risk is removed for each audience.

### Visual Language

- **Green** = Success, Validation, Production
- **Red** = STOP, Error Prevention, Safety
- **Blue** = Intelligence, AI, Processing
- **Purple** = Enterprise, Governance, Control
- **Gold** = Validation, Certification, Quality

## 📊 Stakeholder Views

### 1. Investors 💰
**Focus:** Defensible AI + Scalable Moat

**Key Message:** "Our AI improves only when real machines produce real output — this creates a compounding industrial data moat."

**Emphasizes:**
- Proprietary production data
- Workshop-specific learning
- Machine-specific intelligence
- Non-replicable industrial data
- Continuous improvement loop

### 2. Enterprises 🏢
**Focus:** Control, Safety & Auditability

**Key Message:** "AI never executes directly. Every decision passes certified validation and can be audited."

**Emphasizes:**
- Validation layers
- Certified baselines
- Audit trails
- Human override
- Operation modes (Sandbox/Production/Certified)

### 3. Workshops 🔧
**Focus:** Speed, Fewer Mistakes, More Money

**Key Message:** "The system catches mistakes before the machine does."

**Emphasizes:**
- Before vs After workflow
- Time savings (93% reduction)
- Material savings (15-20%)
- Error prevention at every step
- QR feedback loop

### 4. Machine Suppliers ⚙️
**Focus:** Fewer Errors, Happier Customers

**Key Message:** "We reduce machine misuse and protect your brand in the field."

**Emphasizes:**
- Machine-specific adapters
- Safety validation
- Invalid G-code prevention
- Reduced support tickets
- Brand protection

### 5. Profile Suppliers 🏗️
**Focus:** Digital Assets

**Key Message:** "Your profiles are fabricated exactly as engineered — every time."

**Emphasizes:**
- Certified profile logic
- Role assignment enforcement
- Reduced misuse
- System pack integration
- No-DXF tuning (88% parameters)

### 6. Governments 🏛️
**Focus:** Transparency & Accountability

**Key Message:** "Every component is traceable from specification to production."

**Emphasizes:**
- Immutable records
- Complete audit trail
- Machine passports
- ACID transactions
- Fair procurement
- Compliance readiness
