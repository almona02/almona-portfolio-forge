# 👷 Operator Manual - Mahmoud

**Role:** Workshop Operator / Cutter
**Tool:** Kiosk Mode (Production View)

---

## 🖥️ The Kiosk Interface
Your interface is simple. Big buttons. Clear numbers.

### 1. The Queue (الطابور)
*   You see a list of jobs: **"Ready for Cutting"**.
*   Select the top job.

### 2. Cutting List (قائمة القص) ✂️
*   **DO NOT CALCULATE.** The system does it for you.
*   You will see:
    *   **Profile Image**: (e.g., Frame PANDA-50)
    *   **Length**: (e.g., 1250 mm)
    *   **Quantity**: (e.g., x2)
    *   **Angles**: (e.g., 45° / 45°)

### 3. Step-by-Step
1.  **Scan**: If you have a barcode, scan the profile.
2.  **Cut**: Set the saw to the angle shown on screen.
3.  **Mark**: Write the "Part ID" (e.g., `W1-F1`) on the piece.
4.  **Done**: Tap the big green **"DONE"** button.

## 🛑 Safety Triggers
*   If the system flags a **"Complex Cut"** (compound angle), a Red Warning will appear. Call the supervisor.
*   **"Glass Size"**: Do not measure glass from the frame. Use the "Glass Order" sheet generated by the system.

---
*Measure Twice, Cut Once. Trust the Machine.*
