# Training Materials

This directory contains training materials for the Almona Portfolio Forge platform.

## Structure

```
docs/training/
├── videos/              # Video tutorials
├── tutorials/            # Step-by-step guides
├── troubleshooting/     # Troubleshooting guides
├── quick-reference/     # Quick reference cards
└── faq/                # Frequently asked questions
```

## Available Materials

### Videos
- `getting-started-arabic.mp4` - 10-minute Arabic getting started video

### Tutorials
- `first-project-tutorial-en.pdf` - English step-by-step guide
- `first-project-tutorial-ar.pdf` - Arabic step-by-step guide

### Troubleshooting
- `troubleshooting-guide-en.pdf` - English troubleshooting flowchart
- `troubleshooting-guide-ar.pdf` - Arabic troubleshooting flowchart

### Quick Reference
- `quick-reference-card-en.pdf` - English printable cheat sheet
- `quick-reference-card-ar.pdf` - Arabic printable cheat sheet

### FAQ
- `faq-en.pdf` - English FAQ (20+ questions)
- `faq-ar.pdf` - Arabic FAQ (20+ questions)

## Usage

These materials are designed for:
- New workshop onboarding
- User training sessions
- Self-paced learning
- Reference during daily operations

## Updates

Training materials are updated regularly based on:
- User feedback
- Feature updates

- Beta testing insights
