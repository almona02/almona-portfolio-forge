# Anchor Client POC: Time-Motion Study Template
## Measuring Process Improvements

**Document Classification:** Measurement Framework  
**Purpose:** Objective measurement of time savings and process improvements  
**Audience:** Client Production Manager + ALMONA Team  
**Duration:** 12 weeks (Week 5-16)

---

## Executive Summary

This template provides a standardized framework for measuring time savings and process improvements during the Anchor Client POC. It ensures objective, comparable measurements that validate the 40% time savings target.

**Key Principle:** Measure actual time, not estimates. Use time-motion study methodology, not self-reported data.

---

## 1. Study Methodology

### 1.1 Time-Motion Study Approach

**What We Measure:**

- **Actual Time:** Stopwatch measurement of actual work time
- **Not Estimates:** No self-reported "I think it took X hours"
- **Not Ideal Time:** No "if everything went perfectly" estimates
- **Real Conditions:** Measure in actual production environment

**Measurement Method:**

1. **Observer Present:** ALMONA team member observes and times
2. **Stopwatch Timing:** Start/stop for each process step
3. **Interruption Logging:** Document interruptions and delays
4. **Multiple Measurements:** Measure each project 3 times (average)

### 1.2 Baseline Measurement (Current Process)

**Before ALMONA Implementation:**

- Measure current process for 3 projects (same types as POC projects)
- Use same observer and timing methodology
- Document all steps and time for each step
- Calculate total time and time per step

**Baseline Projects:**

- Project A (Unitized Curtain Wall) - Current process
- Project B (Stick System Facade) - Current process
- Project C (Complex Skylight) - Current process

### 1.3 ALMONA Measurement (New Process)

**After ALMONA Implementation:**

- Measure ALMONA process for same 3 project types
- Use same observer and timing methodology
- Document all steps and time for each step
- Calculate total time and time per step

**ALMONA Projects:**

- Project A (Unitized Curtain Wall) - ALMONA process

## 5. Multiple Measurement Protocol

### 5.1 Why Multiple Measurements

**Reduce Variance:**

- Single measurement may have outliers (good day/bad day)
- Multiple measurements provide average (more reliable)
- Statistical significance (3 measurements minimum)

### 5.2 Measurement Schedule

**For Each Project Type:**

- **Measurement 1:** Week 9-10 (first project of this type)
- **Measurement 2:** Week 11-12 (second project of this type)
- **Measurement 3:** Week 13-14 (third project of this type)

**Averaging:**

- Calculate average time for each step (across 3 measurements)
- Calculate average total time (across 3 measurements)
- Use averages for improvement calculation

### 5.3 Statistical Analysis

**Variance Calculation:**

- Calculate standard deviation for each step
- Identify outliers (measurements >2 standard deviations from mean)
- Exclude outliers from average (if justified)

**Confidence Level:**

- 3 measurements: 80% confidence
- 5 measurements: 90% confidence (if time permits)

## 11. Measurement Best Practices

### 11.1 Observer Guidelines

**Observer Role:**

- ✅ Time each step accurately (start/stop stopwatch)
- ✅ Document interruptions and delays
- ✅ Note any anomalies or issues
- ✅ Remain neutral (don't influence process)

**Observer Should NOT:**

- ❌ Help with the work (observer, not participant)
- ❌ Suggest improvements during measurement
- ❌ Interrupt the process (unless safety issue)
- ❌ Bias the measurement (favor one process over another)

### 11.2 Measurement Environment

**Consistent Conditions:**

- Same operator/user for baseline and ALMONA measurements
- Same project complexity (similar panel counts, geometries)
- Same time of day (if possible, to account for fatigue)
- Same machine/tools (for CNC preparation)

**Document Variations:**

- If conditions differ, document the differences
- Note impact on measurement (if any)
- Adjust analysis accordingly (if justified)
