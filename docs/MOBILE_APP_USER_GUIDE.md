# Fabricator Pro Mobile - User Guide

## Getting Started

### Installation

1. Download from App Store (iOS) or Google Play (Android)
2. Open the app and sign in
3. Grant camera permissions when prompted

### First Time Setup

1. **Connect to Account**
   - Sign in with your Fabricator Pro account
   - Verify connection to web app

2. **Configure Settings**
   - Set default location
   - Configure barcode format preferences
   - Enable offline mode

## Core Features

### Barcode Scanning

#### Scanning Remnants

1. Open the app and navigate to "Scan Remnant"
2. Point camera at barcode
3. App will automatically recognize and process
4. Verify remnant details on screen
5. Confirm location and save

#### Scanning Jobs

1. Navigate to "Jobs" tab
2. Select a job
3. Scan barcode to mark cuts as complete
4. Progress updates in real-time

### Offline Mode

#### Working Offline

- App automatically queues operations when offline
- All scans and updates are saved locally
- Operations sync automatically when connection is restored

#### Checking Sync Status

- View sync queue in settings
- See pending operations count
- Manually trigger sync if needed

### Job Progress Tracking

#### Viewing Jobs

1. Navigate to "Jobs" tab
2. See list of active jobs
3. View job details and progress

#### Updating Progress

1. Select a job
2. Scan barcode to complete cuts
3. Update job status if needed
4. Changes sync automatically

## Troubleshooting

### Camera Not Working

2. Restart the app

4. Review failed operations
5. Contact support if issues persist

1. Update to latest version

## FAQ

### Q: Can I use the app without internet?

A: Yes! The app works offline and syncs when connection is restored.

### Q: How do I sync my data?

A: Sync happens automatically when online. You can also manually trigger sync in settings.

### Q: What if a scan fails to sync?

A: Failed operations are saved in the sync queue. Review and retry from settings.

### Q: Can multiple users scan the same remnant?

A: Yes, but conflicts may occur. The app will prompt you to resolve conflicts.

### Q: How do I update the app?

A: Updates are available through App Store (iOS) or Google Play (Android).
