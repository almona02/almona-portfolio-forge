# Security Policy

## Reporting Vulnerabilities

Please report security vulnerabilities to: security@almona.com

## Response Time

We will:
- Acknowledge receipt within 24 hours
- Provide regular updates every 48 hours
- Fix critical issues within 7 days

## Security Updates

Subscribe to our security advisories at: 
https://github.com/almona/almona-portfolio-forge/security/advisories
