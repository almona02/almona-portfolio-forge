# Early Access Program - Workshop Agreement

## Program Overview

**Program Name:** Almona Portfolio Forge Early Access Program  
**Duration:** 3 weeks (Weeks 8-10)  
**Participants:** 3 Egyptian workshops (Cairo, Alexandria, Upper Egypt)  
**Purpose:** Real-world validation of Phase 1 features before full launch

---

## Workshop Commitments

### 1. Testing Requirements

- **Minimum Projects:** Complete at least 3 real projects using the system
- **Feature Coverage:** Test at least 2 of the following features:
  - Fly Screen Presets
  - Quick Order Mode
  - Egyptian Special Presets
  - Custom Mullion Validation

### 2. Feedback Requirements

- **Weekly Feedback Sessions:** Participate in 1-hour weekly feedback sessions
- **Structured Surveys:** Complete feedback surveys after each project
- **Accuracy Validation:** Compare system BOM vs. actual production results
- **Issue Reporting:** Report any bugs or issues immediately

### 3. Data Sharing

- **Project Data:** Share project dimensions, materials, and outcomes (anonymized)
- **Accuracy Measurements:** Provide actual measurements vs. system predictions
- **Time Tracking:** Record time spent with/without system
- **Material Waste:** Measure actual material waste vs. system predictions

---

## Almona Commitments

### 1. System Access

- **Full Feature Access:** Complete access to all Phase 1 features
- **Priority Support:** Dedicated support channel with <2 hour response time
- **Training:** 1-2 hours of onboarding and training per workshop
- **Documentation:** Complete documentation and video tutorials

### 2. Support

- **Weekly Check-ins:** Scheduled weekly calls to address questions
- **Bug Fixes:** Priority bug fixes for critical issues
- **Feature Requests:** Consideration of feature requests for Phase 2

### 3. Benefits

- **Free Access:** No cost during early access period
- **Extended Trial:** 3 months free access after program completion
- **Recognition:** Featured as early adopter (if desired)
- **Influence:** Direct input on Phase 2-3 feature prioritization

---

## Confidentiality

- **NDA:** Both parties agree to maintain confidentiality
- **Data Privacy:** Workshop data used only for system improvement
- **Anonymization:** All public reports will be anonymized
- **No Public Disclosure:** Workshop names not disclosed without permission

---

## Success Criteria

### For Workshops:
- ✅ Complete minimum 3 projects
- ✅ Provide accurate feedback
- ✅ Report issues promptly
- ✅ Participate in feedback sessions

### For Almona:
- ✅ 99.5%+ accuracy validated in production
- ✅ No critical usability blockers
- ✅ Positive feedback on core features
- ✅ Clear prioritization for Phase 2
