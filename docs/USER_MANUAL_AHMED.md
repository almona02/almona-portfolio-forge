# 🏭 دليل المالك - أحمد (Workshop Owner Manual)

Welcome back, **Ahmed**! Here is how to use the **Design Wizard** to get jobs done quickly.
مرحباً بك يا **أحمد**! إليك كيفية استخدام **معالج التصميم** لإنجاز العمل بسرعة.

---

## 🚀 1. Start a New Project (بدء مشروع جديد)
1. Click the **"Wizard Mode"** button (wizard icon 🪄) in the Engineering Bay.
   * اضغط على زر **"وضع المعالج"** (أيقونة العصا السحرية 🪄).
2. You will see the **7-Step Wizard**.
   * سوف ترى **معالج الـ 7 خطوات**.

## 🎨 2. The 7 Steps (الخطوات السبعة)

### Step 1: Window Type (نوع الشباك)
* Select **Fixed**, **Sliding**, **Turn**, or **Door**.
* اختر **ثابت**، **جرار**، **مفصلي**، أو **باب**.
* 💡 *Tip: Large icons make it easy!* / *نصيحة: الأيقونات الكبيرة تجعل الاختيار سهلاً!*

### Step 2: System Pack (النظام)
* Choose a system (e.g., **PANDA-50**, **ECO-40**).
* اختر النظام (مثلاً **PANDA-50**).
* Uses "Recommended" tags to help you decide.
* استخدم علامات "موصى به" للمساعدة.

### Step 3: Dimensions (المقاسات) 📏
* Enter **Width** and **Height** in cm.
* ادخل **العرض** و **الارتفاع** بالسنتيمتر.
* ⚠️ If you enter a size that is too big, the **Educational Gate** will stop you and explain why!
* ⚠️ إذا ادخلت مقاس كبيراً جداً، ستقوم **بوابة التعليم** بتنبيهك وشرح السبب!

### Step 4: Template (التصميم)
* Pick a layout (e.g., "2 Sash Sliding").
* اختر شكلاً (مثلاً "2 ضلفة جرار").

### Step 5: Review (المراجعة)
* Check everything one last time.
* راجع كل شيء مرة أخيرة.

### Step 6: Optimization (التحسين) 💰
* See exactly how many bars you need and the **Waste %**.
* اعرف بالضبط عدد العيدان المطلوبة و **نسبة الهالك**.
* See your estimated **Profit Margin**.
* شاهد **هامش الربح** المتوقع.

### Step 7: Production (الإنتاج) 🏭
* Send to the workshop floor!
* أرسل أمر الشغل للورشة!

---

## 🆘 Troubleshooting (حل المشاكل)
* **"Design Invalid"**: check your width/height limits.
* **"Waste High"**: try spliting the window or changing quantity.
