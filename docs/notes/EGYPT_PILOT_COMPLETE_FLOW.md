## 📋 **DETAILED STEP-BY-STEP FLOW**

### **STEP 1: From Home Screen to Project Creation**

#### **1.1 Access Fabricator Workflow**
- **Location:** Home Screen / Dashboard
- **Action:** Click **"New Project"** button or navigate to `/fabricator-workflow`
- **Time:** < 2 seconds
- **Auto-Applied:**
  - Region: Egypt
  - Currency: EGP
  - Egyptian engineering standards: ON

#### **1.2 Egyptian Project Wizard Opens**
- **Location:** Modal Dialog
- **Step 0: Material Selection (FIRST STEP)**
  - **Visual:** Two large cards side-by-side
  - **Options:**
    - **Aluminum** (Blue card) → Auto-selects: **PS System Pack**
    - **UPVC** (Green card) → Auto-selects: **FoxyWin System**
  - **Action:** Click material choice
  - **Auto-Applied:**
    - System pack (PS for Aluminum, FoxyWin for UPVC)
    - Egyptian defaults (color, glazing, constraints)
    - Wind zone based on governorate
  - **Time:** < 3 seconds

#### **1.3 Project Details (Same Step)**
- **Fields:**
  - Client Name: [Enter]
  - Project Name: [Enter]
  - Site/Address: [Optional]
- **Action:** Fill required fields
- **Time:** 10-15 seconds

#### **1.4 Complete Wizard**
- **Action:** Click **"Create Project"**
- **Auto-Applied:**
  - System pack ID
  - Egyptian constraints
  - Default pattern: "2-sash sliding" (most common)
- **Result:** Project created, navigates to Measuring tab
- **Time:** < 1 second

**Total Step 1 Time:** ~15-20 seconds

---

### **STEP 2: Measurement & Design (Auto-Optimized)**

#### **2.1 Smart Measuring Interface**
- **Location:** Measuring Tab (auto-opened)
- **Fields:**
  - Width: [Enter dimensions in mm]
  - Height: [Enter dimensions in mm]
- **Auto-Applied:**
  - Measurement mode: "Hole Size" (Rule 18)
  - Wall deduction: 15mm (Egyptian standard)
  - Color: Default for region
  - Glazing: Standard double glazing
- **Action:** Enter width × height
- **Time:** 5-10 seconds

#### **2.2 Auto-Pattern Selection**
- **Trigger:** After dimensions entered
- **Default Pattern:** "2-Sash Sliding" (most common in Egypt)
- **Auto-Applied:**
  - Grid layout: 1 row × 2 columns
  - Cell types: Both sliding
  - Opening directions: Left + Right
- **Action:** Auto-applied, no click needed
- **Optional:** User can change pattern if needed (1 extra click)
- **Time:** 0 seconds (automatic)

#### **2.3 Design Tab (Auto-Navigated)**
- **Location:** Design Tab (auto-opened after measurement)
- **Display:**
  - Pattern already applied
  - Grid visualization shown
  - Components generated automatically
- **Action:** Review and confirm (or adjust if needed)
- **Time:** 5-10 seconds

#### **2.4 Auto-Optimization**
- **Trigger:** Automatic after design complete
- **Process:**
  - Generates cutting plan
  - Uses real profile dimensions (PS/FoxyWin)
  - Optimizes material usage
  - Calculates frame + sash cuts separately
- **Result:** Optimization complete, navigates to Optimization tab
- **Time:** 2-5 seconds (background)

**Total Step 2 Time:** ~15-25 seconds

---

### **STEP 3: Export & Production (One-Click)**

#### **3.1 Optimization Tab (Auto-Opened)**
- **Location:** Optimization/Production Tab
- **Display:**
  - Visual cutting plan (frame + sash shown separately)
  - Utilization percentage
  - Waste calculation
  - Cost breakdown
- **Review Time:** 5-10 seconds (optional)

#### **3.2 One-Click Export Panel**
- **Location:** Top of Optimization tab (highlighted orange panel)
- **Options:**
  1. **PDF Export** (Blue button)
     - Cutting list with diagrams
     - Frame + Sash cuts shown separately
     - QR code for tracking
  2. **DXF Export** (Green button)
     - CNC-ready format
     - All profiles included
     - Frame + Sash labeled
  3. **Split PO Export** (Orange button)
     - 3 separate POs (Profile, Glass, Accessory)
     - Installation materials included
- **Action:** Click desired export button
- **Result:** File downloads immediately
- **Time:** < 2 seconds

**Total Step 3 Time:** ~7-12 seconds
